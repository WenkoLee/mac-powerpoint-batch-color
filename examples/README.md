# 自制示例

打开 `BatchColorDemo.pptx` 进行试用。共 3 页，含原生形状、文字、组合、表格和虚构柱形图；没有宏、客户内容或外部链接。

- 旧色：`204F92`。
- 接近的颜色：`215092`（填充）、`265092`（线条/表格边框）。
- 保留的其他色：`AA33CC`。
- 目标固定色示例：`112233`。
- 目标主题色示例：`T2`，主题色首行第 4 格。

建议先只选择第 1 页改色，检查第 2/3 页是否保持原样，再点击插件“撤销上次改色”。选“所有页”可体验全文件替换。

第 1 页右下角的 `112233` 使用“华文琥珀”字体名称，可用于检查复制文字后粘贴为纯文本。本项目不附带该字体文件。
