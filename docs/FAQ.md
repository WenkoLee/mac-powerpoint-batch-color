# 常见问题

## 为什么扫描不到我看到的颜色？

可能是对象使用了主题色、渐变、图片像素，或者属于当前范围外的页面。先确认处理范围和旧色色号；需要时适度增加相近范围，并核对候选列表。

## 相近范围是否会把其他颜色也改掉？

扫描只生成候选列表。你可以逐项取消勾选，最终只替换勾选的具体色号。建议先用范围 0 检查精确色，再逐步扩大。

## 输入 112233 为什么不是错误？

HEX 色号允许数字 0—9 和字母 A—F，`112233` 表示一种深色。不能只按“是不是蓝色”判断格式是否有效。

## 选择第 4 格应该填什么？

点击主题色块 **T2**。不要用 A1 代替第 4 格；A1 对应主题色首行第 5 格。

## 粘贴后没有变化？

查看输入框上方的提示。剪贴板可能包含整个形状、图片、过长内容，或者含不属于色号的可见字符。请复制色号文字，再粘贴。格式无效时插件保留原输入。

## 为什么撤销要用插件按钮？

PowerPoint 的常规撤销不保证完整覆盖 VBA 对图表等对象的改动。插件单独记录最近一次改色。请保持对应文件打开，并尽量在对象结构变化前回退。

## 文件是否会自动保存或上传？

插件在当前打开的演示文稿中修改对象，不自动保存、不上传文件，也不包含联网、遥测或登录功能。保存由 PowerPoint 和用户决定。

项目从 Mac PowerPoint 的工作需求出发，纯文本粘贴使用 macOS 接口。Windows 与其他平台未作为当前支持范围进行验收。
