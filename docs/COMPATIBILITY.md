# 兼容性与限制

当前为 **0.1.0-beta.1 测试版**。发布范围限定为 Mac 桌面版 PowerPoint；以下区分实际验证和未验证项。

## 本次验收环境

| 项目 | 环境 |
| --- | --- |
| macOS | 27.0.1，build 26A434 |
| PowerPoint | 16.113.4，build 16.113.26100421 |
| 芯片架构 | arm64 / Apple Silicon |
| 构建依赖 | Python 3.10+，pyOpenVBA 6.1.2 授权快照 |

运行结果见 [验收记录](acceptance/ACCEPTANCE.md)。其他 macOS/Office 版本与 Intel Mac 尚未作为本次测试组合验证；这不等同于已确认不兼容。

## 当前范围

| 对象或行为 | 处理范围 |
| --- | --- |
| 原生形状 | 固定 RGB 填充和线条 |
| 原生文字 | 可访问文字片段的固定 RGB |
| 组合 | 递归处理可访问子对象 |
| 表格 | 单元格填充、文字及可访问边框 |
| 图表 | 系列与数据点的可访问填充和线条 |
| 页面背景 | 可访问前景色；不是完整背景样式重建 |
| 母版与版式 | 仅“所有页”范围遍历其中的可访问形状 |
| 已绑定主题色的旧对象 | 一般形状/文字会跳过；图表存在下述 Mac 接口限制 |
| 图片、截图、视频 | 不修改像素 |
| 渐变、SmartArt、特殊图表元素 | 不承诺完整处理，需检查 |

## 撤销边界

插件只记录最近一次改色，记录在内存中。关闭文件、退出 PowerPoint、卸载插件或执行下一次替换后，不能依靠这份记录回退更早操作。

撤销记录使用页面/对象路径。若在改色后删除对象、重新组合或改变图表结构，可能只能恢复部分内容。推荐改色后立即检查，必要时先使用插件撤销，再继续结构编辑。

## 图表主题色与格式边界

本次验证中，将图表改为 T2 后，实际 RGB 正确，保存后的图表系列填充与线条均保留 `schemeClr=dk2` 主题关联；但 Mac VBA 的 `ObjectThemeColor` 返回 0，`Type` 返回 RGB。不能依赖这些读取值可靠排除图表中原本已绑定主题色的颜色。

修改图表系列时，Mac PowerPoint 会重置单独设置的数据点颜色。本版先保存数据点颜色，再恢复未匹配的数据点，并让插件撤销先恢复系列、再恢复数据点。已验证的回退覆盖示例中的固定 RGB 颜色；数据点原有的自动继承、主题关联、纹理或透明度不作为“完整格式回退”的保证范围。

## 快捷键边界

文本框实现了 Mac Command 快捷键与控制字符处理。电脑操作工具对 Command 修饰键和鼠标选区的模拟表现与实体键盘可能不同。已实测 Control+A/C/X/V；实体 Command 快捷键、部分文字选择与文本撤销/重做尚待补测。验收记录明确区分这些范围。

## 字体与安装

界面优先使用 Microsoft YaHei；未安装时可能由 Office/macOS 替代。项目不分发字体文件。

插件未签名；组织策略可能限制加载。安装、恢复宏保护及重启后的验证方式见 [安装说明](INSTALL.md)。

本轮测试版在加载时临时关闭了宏保护，测试后由用户确认恢复。测试版随后已移除，所以恢复保护后的测试版冷启动加载/运行未验证；不要据此假定任何宏策略下均可运行。
